## Download

| File | Use it when |
|---|---|
| **TwiceCorrupted-Setup-VERSION.exe** | You want a normal install: Start-menu shortcuts, optional desktop icon, uninstaller. No admin rights needed. |
| **TwiceCorrupted-VERSION-portable.zip** | You'd rather not install anything: unzip anywhere you can write to and run `TwiceCorrupted.exe`. |

**In-game hotkeys:** if Path of Exile runs as administrator, start the app with the **Twice Corrupted (admin, for in-game hotkeys)** shortcut (portable: run `TwiceCorrupted.exe --elevate`).

**"Windows protected your PC"?** The exe isn't code-signed yet, so SmartScreen may warn on first run. Click **More info → Run anyway**.
